Process

From push to review in seconds

A pull request triggers the full pipeline automatically. No configuration needed beyond installing the app.

01

Install the GitHub App

Connect CodeLens to your repositories. It immediately begins ingesting past review comments to build the retrieval corpus.

02

Open or push a PR

On every opened, reopened, or synchronize event, one bounded review job is queued for the PR head.

03

Receive structured feedback

The job retrieves similar past patterns, synthesizes concerns via Groq, and posts one grounded review comment directly on the current PR commit.

Features

Built for production

Every part of the pipeline is designed to be fast, fault-tolerant, and grounded in real code history, not generic advice.

Bounded review jobs

Each PR head uses one worker task. Hunk and Groq request caps keep processing within the free-tier budget, and obsolete commits are skipped.

Semantic retrieval

Every hunk is embedded with Voyage AI's code model and searched against a pgvector index of your project's historical review comments at cosine threshold 0.55.

Delta diff on push

Synchronize events use GitHub's three-dot compare endpoint, scanning only the newly pushed commits, not the entire PR diff again.

Idempotent delivery

Every review is keyed on (repo, PR number, commit SHA). Duplicate webhook deliveries or retries silently no-op with no double-posts.

Partial results on timeout

When a configured analysis limit or provider rate limit stops synthesis early, CodeLens posts an explicit incomplete-analysis status.

Cross-repo patterns

The retrieval corpus spans multiple ingested repositories. Patterns from httpx, FastAPI, or Pydantic can surface insights on your own codebase.

Architecture

Retrieval-augmented from the ground up

Every component is chosen for reliability and developer trust: embeddings that understand code, a vector store that scales, and inference fast enough to beat a human's first coffee break.

  • embeddings Voyage AI voyage-code-4 (1024-dim, code-optimized)
  • vector store pgvector on PostgreSQL, cosine similarity search
  • inference Groq LLM API, sub-second synthesis latency
  • task queue Celery with Redis, prefork pool, asyncio-safe
  • runtime FastAPI · Docker · Caddy TLS
  • webhook GitHub App with HMAC-SHA256 signature verification
Eval

Tested against real maintainers

Held-out evaluation on review comments from 5 open-source Python repositories (psf/requests, tiangolo/fastapi, pallets/flask, encode/httpx, pydantic/pydantic). Stratified by repo to prevent any single project from dominating the test set.
